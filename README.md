# Lex CKV Portfolio

Portfolio met dans, film, muziek en schilderkunst.

## Lokaal starten

Installeer Node.js LTS en voer in deze map uit:

```sh
npm run dev
```

Open http://127.0.0.1:3000.

Toegevoegde bestanden worden lokaal in de browser opgeslagen (IndexedDB). Ze staan niet in deze repository en worden niet automatisch gedeeld met bezoekers.
